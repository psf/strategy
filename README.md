# PSF Strategy

This is the official repository for the Python Software Foundation's strategic
plan, maintained in Markdown so changes can be read, discussed, and tracked over
time.

**[Read the current strategic plan](strategy.md).**

The 2026 plan covers **2026–2031**. The PSF Board adopted it on **July 8, 2026**,
with an annual review that incorporates staff and community feedback. The
[adoption and annual review resolutions](https://www.python.org/psf/records/board/minutes/2026-07-08/#new-business)
are recorded in the board's published minutes.

## Reading the plan

The plan sets out six crosscutting organizational goals and four program goals.
The organizational goals describe how the PSF operates. The program goals guide
where it directs its work and resources. Tactical ideas in the plan are starting
points for PSF staff to develop, rather than implementation commitments.

## Reviews and updates

The board reviews the plan no later than the anniversary of its adoption each
year. The review assesses progress, considers changes in priorities, incorporates
staff and community feedback, and publishes a summary of findings and any
changes. Amendments are adopted by a board vote.

Keep the latest adopted plan at `strategy.md` so links continue to work. When an
adopted revision is published, update this copy alongside the python.org page
and add links here to the relevant board decision, blog announcement, and review
summary. Summarize each adopted revision in the [changelog](CHANGELOG.md).
Git history preserves earlier versions and shows how the plan changed.
